# SQL Data Analysis

## 📌 Project Overview

This project focuses on SQL-based data analysis using a Data Warehouse environment.

The project demonstrates how SQL can be used to explore data, analyze sales performance, identify trends, and generate meaningful business insights.

The analysis is performed on customer, product, and sales data stored in a Gold Layer.

---

## 🛠️ Tools & Technologies

- SQL Server
- SQL
- VS Code
- Data Warehouse
- GitHub

---

## 🗂️ Data Warehouse Structure

The project follows a layered Data Warehouse architecture:

- Bronze Layer
- Silver Layer
- Gold Layer

The analysis is mainly performed on the Gold Layer.

### Gold Layer

The Gold Layer contains:

- `gold.dim_customers`
- `gold.dim_products`
- `gold.fact_sales`

## 🔍 Analysis Performed

### 1. Database Exploration

- Explore database tables
- Explore database columns
- Understand database structure

### 2. Dimension Exploration

- Explore customer countries
- Explore product categories
- Explore product subcategories
- Explore product names

### 3. Date Exploration

- Identify earliest order date
- Identify latest order date
- Analyze available sales periods

### 4. Measure Exploration

Calculated important business metrics such as:

- Total Sales
- Total Quantity Sold
- Average Selling Price
- Total Orders
- Total Products
- Total Customers

### 5. Magnitude Analysis

Analyzed:

- Customers by country
- Customers by gender
- Products by category
- Average product cost by category
- Sales and customer-related metrics

### 6. Ranking Analysis

Performed ranking analysis to identify:

- Top 5 products by revenue
- Top 10 customers by revenue
- Highest-performing products and customers

### 7. Advanced Data Analysis

#### Changes Over Time

Analyzed sales performance:

- Year-wise
- Month-wise

Metrics include:

- Total Sales
- Total Customers
- Total Quantity

#### Cumulative Analysis

Analyzed cumulative sales and business performance over time.

#### Performance Analysis

Compared current performance with previous periods and evaluated product/customer performance.

#### Part-to-Whole Analysis

Analyzed how individual products or categories contribute to overall sales.

#### Data Segmentation

Segmented customers and products based on business-related characteristics.
